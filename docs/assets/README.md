# Project branding

`cyberllm-shield.png` is displayed at 160 pixels wide in the repository README.
Its pixel-style shield protects a vehicle and connects to three colored square
nodes representing cooperating AI agents. This ties the emblem to the project's
automotive cybersecurity and guarded-response focus.

The emblem was redesigned with the built-in image-generation tool using the
previous geometric logo as a style reference. The generated PNG is used directly
with its transparent alpha channel preserved.

## Wordmark

`cyberllm-wordmark.svg` is displayed at 560 pixels wide. It uses large, bold
monospace typography in solid black, as requested by the project owner. The
transparent SVG has accessible title text and no external fonts or resources.
The full project subtitle remains selectable text in the README.

## Emblem generation prompt

Redesign the supplied emblem for the specific subject 'CyberLLM: A Multi-Agent LLM Framework for Autonomous Detection and Guarded Response in Automotive Cybersecurity'. Preserve the reference's simple flat geometric/pixel aesthetic and restrained coral, muted blue, warm yellow palette, but replace the abstract letter C with a clearly meaningful symbol. One compact stepped pixel shield encloses a very simple front-view vehicle silhouette, made from a few solid rectangular blocks and negative space. Three tiny square agent nodes connect to the top of the shield with clean right-angle lines, representing cooperating AI agents guarding the vehicle. The shield and car are dark navy / near-black; the three small agent squares are coral, blue and yellow. A minimal professional open-source research logo, not a detailed illustration. Flat solid colors, exact grid alignment, crisp edges, balanced symmetry, ample negative space. Keep car and shield readable at 160 pixels. Absolutely no gradients, glow, shadows, glossy material, texture, robots, faces, large circles, letters or words. Transparent background with real alpha. Square composition; one coherent logo occupying 75 percent of the canvas. The large black CyberLLM wordmark is handled separately and must not appear inside this image.
